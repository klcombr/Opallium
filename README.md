# Opallium

Página de apresentação (landing page) do Opallium, um workspace minimalista de produtividade em tela cheia com widgets flutuantes. Apresenta a proposta do projeto, seus módulos e dá acesso ao workspace hospedado.

## Funcionalidades

- Seção hero com apresentação do workspace e botão de acesso.
- Seção de arquitetura modular destacando os 20 widgets integrados.
- Cards de funcionalidades: produtividade, motores de tempo, ambiente dev com IDE CSS e física com inércia.
- Cursor customizado com física LERP e janela de preview animada com efeito de inclinação.
- Aparência customizável via arquivos `.css` independentes.

## Como usar

O projeto é uma página estática. Abra `index.html` no navegador ou sirva a pasta com um servidor estático:

```bash
python -m http.server
```

E acesse `http://localhost:8000`.
